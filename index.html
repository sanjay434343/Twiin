Install in three steps.

  1. Download the APK with the button above.
  2. Open the file. If Android asks, allow installs from your browser or file manager.
  3. Open Twiin and add your first card.

Twiin keeps digital references to your cards. It is not a payment, NFC or government ID credential, so carry the original when a service requires it.
